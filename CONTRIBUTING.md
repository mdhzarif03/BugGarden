# Contributing to BugGarden

Thank you for taking the time to contribute to BugGarden! We welcome bug fixes, new coding challenges, UI improvements, and documentation updates.

## How to Get Started

1. **Fork & Clone**
   Fork the repository on GitHub and clone your fork locally:

   ```Shell
   git clone [https://github.com/your-username/BugGarden.git](https://github.com/your-username/BugGarden.git)
   cd BugGarden
   ```

2. **Install Dependencies**

   ```Shell
   npm install
   ```

3. **Run the Development Server**

   ```Shell
   npm run dev
   ```

   Open `http://localhost:3000` in your browser to view the application.

## Submitting Changes

1. **Create a Feature Branch**

   ```Shell
   git checkout -b feature/your-feature-name
   ```

2. **Commit Your Changes**
   Keep your commit messages clear and descriptive:

   ```Shell
   git commit -m "Add new beginner Python challenge"
   ```

3. **Push & Create a Pull Request**
   Push your branch to your GitHub fork and open a Pull Request targeting the `main` branch. Provide a concise summary of the changes made.
