# BugGarden 🐛🪴

> Find the bug. Fix the code. Understand why.

BugGarden is a tiny open-source debugging playground built around a simple idea: debugging is not just fixing code — it is learning to think about why code behaves the way it does.

## Features

- ⚡ **Client-Side WASM Execution**: Safe code testing using Pyodide Python WebAssembly.
- 🎯 **Focused Logic Puzzles**: 12 curated initial challenges spanning Syntax, Logic, Loop, and List bugs.
- 💡 **Progressive Hinting**: Built-in 3-tier hints per challenge.
- 🚀 **Zero Infrastructure**: No database required; local progress persisted in `localStorage`.

## Getting Started

```bash
git clone [https://github.com/your-org/buggarden.git](https://github.com/your-org/buggarden.git)
cd buggarden
npm install
npm run dev
```
